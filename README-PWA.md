# Multiverse Runner — PWA package

## Состав

- `runner.html` — игра.
- `manifest.webmanifest` — манифест устанавливаемого приложения.
- `sw.js` — Service Worker и офлайн-кэш.
- `offline-utilities.css` — локальные CSS-утилиты и автономные символьные иконки.
- `icons/` — иконки приложения.

## Запуск

PWA и Service Worker не работают при открытии файла напрямую через `file://`. Разместите **все файлы и папку `icons` вместе** на HTTPS-хостинге или запустите локальный сервер на `localhost`.

### Локальная проверка

Из каталога с `runner.html` выполните:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/runner.html`.

### Установка

- **Chrome / Edge на компьютере:** откройте игру по HTTPS или localhost; используйте значок установки в адресной строке или кнопку «Установить» внизу игры, когда браузер её покажет.
- **Android:** откройте игру в Chrome и выберите «Установить приложение» / «Добавить на главный экран».
- **iPhone / iPad:** откройте игру в Safari → «Поделиться» → «На экран Домой».

Встроенная кнопка установки показывается только там, где браузер предоставляет событие `beforeinstallprompt`. На iOS обычно используется меню «Поделиться».

## Офлайн-работа

После первой успешной загрузки Service Worker кэширует HTML, локальные стили, манифест и иконки. Внешние CDN-зависимости удалены: базовые стили, шрифтовые fallback и символьные иконки работают локально.

Первую загрузку нужно выполнить онлайн/через localhost, чтобы Service Worker установился и создал кэш. При выпуске новой версии увеличьте `CACHE_VERSION` в `sw.js`.

## Сохранения

Игровой прогресс продолжает храниться в `localStorage`. Для переноса профиля на другое устройство используйте встроенный экспорт/импорт сохранений.
